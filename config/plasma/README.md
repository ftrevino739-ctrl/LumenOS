# Plasma configuration

`Lumen.colors` is the initial KDE color-scheme draft.

On a Plasma 6 session, run `scripts/install-theme.sh` as the desktop user (not with sudo). It installs the color scheme in the user's local KDE color-scheme directory and attempts to apply it when the Plasma helper is available.

This does not install a global theme, change system services, or modify the login manager. Panel layout, window decoration, blur and wallpaper integration are separate milestones.
